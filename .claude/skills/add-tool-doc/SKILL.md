# 添加新工具文档

当用户要求添加新工具文档时，执行以下流程：

## 步骤

1. **确定分类目录**
   - 终端工具 → `01-终端工具/`
   - 开发工具 → `02-开发工具/`
   - 输入法 → `03-输入法/`
   - 其他工具 → `04-其他工具/`

2. **创建文档目录**
   ```bash
   mkdir -p <分类目录>/<工具名>
   ```

3. **编写文档 `<工具名>.md`**
   - 简介（是什么、用途）
   - 核心功能
   - 安装方法（Homebrew、官方脚本等）
   - 快速开始示例
   - 配置示例
   - 常用命令
   - 参考资料（官网、GitHub）

4. **提交推送**
   ```bash
   git add <文件路径>
   git commit -m "添加 <工具名> 文档"
   git push origin main
   ```

## 文档格式参考

参考现有文档：`02-开发工具/mise/mise.md`

## 注意事项

- 使用中文编写
- 目录命名遵循数字前缀约定
- commit message 简洁描述
